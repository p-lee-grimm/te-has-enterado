# Примеры фактов и сборок с разбором

Примеры иллюстративные, для калибровки формата. При реальном извлечении факты берутся только из источника.

## Извлечение: персона-политик

**Плохо**
```json
{"fact":"Известный испанский политик, уроженец Галисии","kind":"role"}
```
Оценочное «известный» вне `kind = evaluative`; происхождение вместо нынешней роли. Слой А (`facts.validate_fact`) отклонит.

**Хорошо**
```json
{"fact":"Председатель Народной партии (PP)","kind":"role","topics":["политика"]}
{"fact":"Народная партия — правоцентристская","kind":"classification","topics":["политика"]}
{"fact":"Ранее возглавлял правительство Галисии","kind":"role","topics":["политика","регионы"]}
```
Три атомарных факта вместо одной строки. Сборщик выберет из них два под тему поста.

## Извлечение: бизнесмен

**Плохо**
```json
{"fact":"Председатель Grupo ACS, 786-й в рейтинге Forbes, состояние 3,4 млрд","kind":"role"}
```
Три утверждения в одном факте; рейтинговое место, с которым читателю нечего сравнить; сумма, требующая ежегодного обновления.

**Хорошо**
```json
{"fact":"Председатель Grupo ACS","kind":"role","topics":["экономика"]}
{"fact":"Grupo ACS — одна из крупнейших строительных компаний Европы","kind":"scale","topics":["экономика"]}
{"fact":"Президент футбольного клуба «Реал Мадрид»","kind":"role","topics":["спорт"]}
```
Масштаб дан качественно и не протухает. Разные `topics` — в новости про газету сборщик возьмёт первые два, в новости про стадион третий.

## Извлечение: спорная фигура

**Плохо**
```json
{"fact":"Ультраправый журналист, распространяющий фейки","kind":"evaluative","attribution":"El País"}
```
Атрибуция есть в поле, но отсутствует в тексте факта — в собранном блоке утверждение прозвучит от имени канала. Слой А (`facts.validate_fact`) отклонит.

**Плохо**
```json
{"fact":"Критики называют его ультраправым","kind":"evaluative","attribution":"критики"}
```
Размытая атрибуция: непроверяема и позволяет произнести утверждение, не отвечая за него.

**Хорошо**
```json
{"fact":"Основатель и директор канала EDATV","kind":"role","topics":["медиа"]}
{"fact":"El País описывает EDATV как часть ультраправой медиасреды","kind":"evaluative","attribution":"El País","topics":["медиа","политика"]}
```
Второй факт — проверяемое утверждение о том, что написало конкретное издание. Отвечает за содержание оно.

## Извлечение: процессуальный статус

**Плохо**
```json
{"fact":"Замешан в коррупционном скандале","kind":"legal"}
```
Формулировки нет в словаре; дело не названо; «замешан» — утверждение о причастности.

**Плохо**
```json
{"fact":"Обвиняемый по делу Koldo","kind":"legal","quote":"investigado en el caso Koldo"}
```
Источник говорит `investigado` — это стадия расследования, а не обвинение. Подмена термина возвращает стигму, от которой испанское право ушло в 2015 году.

**Хорошо**
```json
{"fact":"Фигурирует в расследовании по делу Koldo","kind":"legal","topics":["право"],"quote":"investigado en el caso Koldo"}
```
Формулировка из словаря, дело названо, вина не утверждается.

## Сборка под тему поста

Пул тот же, посты разные.

Тема `экономика`, заголовок про долю в газете:
> Председатель Grupo ACS, одной из крупнейших строительных компаний Европы.

Тема `спорт`, заголовок про стадион:
> Президент футбольного клуба «Реал Мадрид», председатель Grupo ACS.

Одна фиксированная карточка не могла бы обслужить оба случая — в этом и смысл пула.

**Недопустимая сборка**
> Председатель Grupo ACS и президент «Реала», давний союзник правых.

Последняя часть отсутствует в фактах. `facts.validate_assembly` поймает её по посторонним словам, и сборка будет отброшена целиком.
